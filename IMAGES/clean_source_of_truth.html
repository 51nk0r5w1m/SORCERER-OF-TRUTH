05 // Application

Case 01: JWT Storage

The tutorial gives you an answer. The threat model gives you the question.

Research Moves

S

Surface Answer

"Store JWT in localStorage" — top Stack Overflow + typical tutorials.

T

Source Trail

RFC 10017 says browser-based apps SHOULD use authorization code + PKCE. OWASP ASVS 3.5.3 explicitly states tokens must not be accessible to JavaScript if possible.

!

The Conflict

Attacker move: An XSS payload calling localStorage.getItem('jwt') allows the token to leave the origin in one line of JS. An httpOnly cookie prevents this entirely.

Working Takeaway

JavaScript-accessible storage fundamentally changes attacker power. The tutorial omits the threat model.

06 // Context

Find the humans behind the spec

Specs tell you what. Working groups, maintainers, issue threads, and conference talks often explain why.

  • Identify the RFC / BCP authors.
  • Check Datatracker + working group history.
  • Map what changed across drafts.

"Sometimes the fastest way to understand the document is to find the person who was tired enough to write it."

07 // Tooling

AI is an Exoskeleton, not a Root of Trust

Use it for:

Orientation, controlled-source summaries, comparison matrices, and question generation.

Do NOT use it for:

Citations, final authority, normative interpretation, or replacing the threat model.
